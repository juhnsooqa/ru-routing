Happ

меньше 1 КБ

Профиль ссылается на наши гео-файлы, приложение скачивает их само и обновляет раз в неделю.

Добавить и включить Только добавить

Профиль обновляется повторным импортом: имя то же — Happ заменит старый, переустанавливать ничего не нужно.

Наведите камеру телефона, чтобы открыть ссылку в Happ.

Incy

автообновление

Incy не поддерживает гео-файлы, поэтому получает полный список по ссылке и сам перечитывает его — список обновляется раз в 2 дня.

Добавить с автообновлением

Разовый импорт ссылкой недоступен: со списком блокировки профиль весит 65 КБ, столько в deeplink не помещается. Используйте вариант с автообновлением выше.

Наведите камеру телефона, чтобы открыть ссылку в Incy.
