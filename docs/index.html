RU routing

Российские сервисы идут напрямую, всё остальное — через туннель. Доменов: 997, категорий: 29. Реклама и трекеры блокируются (913 доменов). Откройте эту страницу на устройстве с установленным приложением и нажмите кнопку.

Happ

Профиль весит меньше килобайта: списки лежат в наших гео-файлах, приложение скачивает их само и обновляет раз в неделю.

Добавить и включить Только добавить

Профиль обновляется повторным импортом: имя то же — Happ заменит старый, переустанавливать ничего не нужно. Гео-файлы приложение тянет само, но не чаще раза в неделю.

Incy

Гео-файлы Incy не поддерживает, поэтому получает полный список по ссылке. Вариант с автообновлением сам перечитывает его — список обновляется раз в 2 дня.

Добавить с автообновлением

Разовый импорт ссылкой недоступен: со списком блокировки профиль весит 62 КБ, столько в deeplink не помещается. Используйте вариант с автообновлением выше.
